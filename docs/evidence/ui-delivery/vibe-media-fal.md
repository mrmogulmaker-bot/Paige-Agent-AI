## User job and state map

Job: "Create governed media for my campaign without leaving Vibe Studio — see what it costs before it runs, approve it, watch it run, review what came back."

States (owner-required 18, mapped):
1. no provider configured → truthful needs_config panel naming FAL_KEY (name only) + existing image providers status
2. provider configured but capability disabled → video/music rows render disabled with reason (flag off / deferred)
3. available image generation → composer active, estimate live
4. video unavailable/feature-flagged → row labeled, behind MEDIA_VIDEO_ENABLED + daily cap truth
5. estimate ready → cost + model + license disclosure before submit
6. awaiting approval → approve/decline actions on the pending job (persisted server-side)
7. queued → provider IN_QUEUE reflected
8. processing → IN_PROGRESS reflected
9. progress where truthful → queue position when provider supplies it; never fake progress bars
10. completed → asset preview from Paige Storage
11. review-ready → approve-for-project / regenerate / discard actions
12. failed → honest error, retry eligible where attempts remain
13. canceled → user-cancelled state, cancel propagated to provider where permitted
14. retry eligible → bounded attempts with backoff (durable contract)
15. budget denied → fail-closed truthful explanation (accrued vs ceiling, resets UTC midnight)
16. content/moderation denied → provider safety failure surfaced as a governed denial, never silent
17. provider unavailable → unreachable outcome with recovery path
18. asset saved + awaiting Social-publish eligibility → publish handoff rendered disabled with: "Social publishing becomes available after this account's Social connection and publishing path are verified."

Scroll owner: the job rail column scrolls; composer + disclosure stay fixed within the overlay (verified per viewport).
