## Scope and collisions

- Classification: Solo UI, presentation-only reskin of an already-shipped surface (the Social Command desk).
- Affected flows: one — the Solo owner reading Campaigns → Social and recording the accounts they post from.
- Neighboring regressions: none. Only social-command.tsx + social-command.css changed; the other five Campaigns tabs, the six-tab shell (growth2.tsx), the projection layer and the hook are untouched, and growth2.contract/render still pass (single tablist, no masthead).
- Active-owner/file collisions: none. No migration, RPC, edge function or hook return shape changed; the frozen solo-campaigns.css (§28) and solo-tokens.css were not touched.
- Explicit exclusions: no live channel connection, publishing/scheduling, ad-spend, measured telemetry, or clipping builder was added — these have no tenant backend seam (confirmed by this session's backend grounding; summarized here), so they render as honest absences rather than dead controls or fabricated numbers. Standing those seams up is separate backend work, flagged to the owner for a §00 round-table decision.
