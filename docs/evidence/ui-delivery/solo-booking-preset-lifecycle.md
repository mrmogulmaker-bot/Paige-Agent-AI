chooser (six recognizable scheduling models + starter templates + Custom), and every preset gains a
real Draft → Publish / Pause lifecycle enforced SERVER-SIDE: creation yields a private draft, and only
an explicit, server-validated Publish makes the public `/book/:slug` page bookable. A shared canonical
RPC seam (create/update/publish/pause/get_calendar_presets) is the ONE path both the UI and Paige use.
Also folds in the quick, isolated removal of the redundant `SOLO SETTINGS / Connections` masthead.
