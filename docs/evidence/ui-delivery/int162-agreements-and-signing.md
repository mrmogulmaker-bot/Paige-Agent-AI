## Review and limitations

Three defects on the signing page were caught by RENDERING it and would not have been caught by
reading it: the read gate was dead (it measured while `display:none`, read 0x0, concluded the
document fitted without scrolling and unlocked signing before a word was read); the gold commit
button had no fill (a reset selector at (0,1,1) beating the component at (0,1,0), which was also
silently stripping the signature field's serif); and a webfont `@import` took the whole page down,
because the stylesheet ships in a lazy-route CSS chunk that Vite's preload helper waits on. The
stylesheet therefore carries NO `@import` by design.

Blocking limitation: [#1355](https://github.com/mrmogulmaker-bot/Paige-Agent-AI/issues/1355) —
`usePageView()` reports `location.pathname` verbatim to `track-event`, writing the bearer signing
token into the analytics store. Measured, not inferred. It already does this on the shipped
`/join/:token`, so it is a live defect rather than one this change introduces, but this page must
not ship over it.
