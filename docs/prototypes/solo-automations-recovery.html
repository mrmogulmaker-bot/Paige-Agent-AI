What makes the first automation possible

The shortest real path, in dependency order. None of it can be done from this screen today.

  1. Give this workspace a pipeline with stagesStage automations attach to a deal moving between stages. This workspace has no pipeline and no deals, so there is nothing to attach a rule to.
  2. Configure a delivery route for automation dispatchThe stage trigger fires and logs correctly, but no workspace has a delivery route set and the platform fallback is absent. Until one exists, a rule that fires records skipped_no_webhook instead of doing anything.
  3. Author the first ruleThis is the one lane whose write contract is real and tenant-safe today: an owner may create, edit and deactivate stage rules. It has no home in this shell yet.
  4. Then, and only then, show runsRun history, success rate and attention counts become truthful the moment real runs exist. Until then this screen shows none of them.
