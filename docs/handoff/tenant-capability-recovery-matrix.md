# PAIGE tenant capability recovery matrix

**Audit date:** 2026-08-21  
**Authority:** mounted repository code first; `src/pages/Admin.tsx` and each component/data seam were inspected. This matrix is an integration contract, not a claim that `/tenant-redesign` is production-connected.

## Classification key

- **Live and connected** — mounted surface with a concrete table, RPC, hook, Storage, Realtime, or Edge Function seam.
- **Live but incomplete** — a real seam exists, but requested breadth, connector readiness, policy integration, or unified view is incomplete.
- **Front-end prototype only** — representative interaction in `/tenant-redesign`; no production seam is invoked there.
- **Planned / owed** — no complete operational implementation was found.

Access labels describe client route gates only. Supabase RLS, tenant membership, effective actor, and server authorization remain authoritative.

## Security invariant

The matrix never grants access. Production integration must resolve global `user_roles`, tenant `tenant_members`, and agency `agency_team_members` independently; enforce RLS; and preserve real/effective actor logging for operator or agency act-as. A generic `admin` label is not an authorization model.
